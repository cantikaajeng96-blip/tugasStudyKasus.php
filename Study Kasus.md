# &#x09;	Study Kasus

Soal 1 :

&#x20;Sebuah tempat villa sejuk asri ingin membuat sistem sederhana menggunakan HTML dan PHP untuk menghitung biaya sewa villa berdasarkan jenis villa dan lama menginap.

&#x20;

Ketentuan Harga Permalam :

Standard = Rp.350.000

Deluxe =  Rp.550.000

Family = Rp.850.000



Jika  menginap 3 malam atau lebih, pelanggan mendapatkan diskon 15% dari total biaya.

Jika menginap kurang dari 3 malam, pelanggan tidak mendapat diskon.



Soal 2 :

&#x20;Bengkel mobil maju jaya ingin membuat sistem sederhana untuk menghitung biaya service pelanggan secara otomatis agar proses pembayaran lebih cepat dan mengurangi kesalahan perhitungan.



Ketentuan :

* Ganti oli = Rp.150.000
* Tune up = Rp.300.000
* Service lengkap = Rp.500.000



Jika biaya service lebih dari Rp.400.000 maka pelanggan mendapatkan diskon 10%

Jika biaya service Rp.400.000 atau kurang, pelanggan tidak mendapatkan diskon.



Soal 3 :

&#x20;Sebuah tempat rental PlayStation masih menghitung biaya sewa secara manual. Karena itu, kadang petugas salah menghitung total pembayaran, di buatlah program sederhana menggunakan HTML dan PHP.

Di rental ini tersedia beberapa pilihan PlayStation dengan tarif sebagai berikut :



* PS 3 = Rp.8000 / jam
* PS 4 = Rp.12.000 / jam

&#x20;

kalau pelanggan bermain lebih dari 5 jam, akan mendapatkan diskonn 10%.

kalau bermain 5 jam atau kurang, tidak mendapatkan diskon
